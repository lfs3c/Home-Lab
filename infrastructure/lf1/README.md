# LF1

LF1 is the primary Home Lab server.

## Verified Platform

- Hardware platform: Apple iMac14,2
- CPU: Intel Core i5-4570
- CPU topology: 4 cores / 4 threads
- Architecture: x86_64
- Operating system observed during the latest inventory: Debian GNU/Linux 12 (Bookworm)
- Kernel observed: Linux 6.1 series

## Storage

The latest inventory identified three physical disks:

- approximately 1 TB system disk
- approximately 2 TB data disk used for PhotoPrism data
- approximately 5 TB external disk associated with backup storage

Exact device identifiers and operational mount details are intentionally omitted from this public overview.

## Documentation Policy

Services are documented separately from the physical host. A service should appear as a current LF1 service only after its live state has been verified.

Sensitive network addressing, credentials, tokens, MAC addresses, serial numbers, and private configuration are not published here.
