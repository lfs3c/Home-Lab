# LF1

LF1 is the primary Home Lab server.

## Verified Platform

- Hardware platform: Apple iMac14,2
- CPU: Intel Core i5-4570
- CPU topology: 4 cores / 4 threads
- Architecture: x86_64
- Operating system: Debian GNU/Linux 12 (Bookworm)
- Kernel: Linux 6.1 series

## Storage

The current inventory confirms three storage roles:

- system storage
- dedicated PhotoPrism data storage
- dedicated backup storage

Exact device identifiers and operational mount paths are intentionally omitted from this public overview.

## Current Home Lab Roles

LF1 currently hosts services for:

- media and personal cloud
- monitoring and infrastructure management
- automation
- communication
- network services
- container management
- Home Lab administration

Individual services are documented under `services/` rather than tied structurally to this host.

## Administration Project

Hermes Control API is currently active on LF1. Its project documentation is kept separate from generic host documentation.

## Documentation Policy

A service is presented as current only after its live state has been verified. Sensitive network addressing, credentials, tokens, MAC addresses, serial numbers, and private configuration are not published here.
