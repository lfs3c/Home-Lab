# Remote Access and Traffic Routing

LF1 currently provides supporting access and routing infrastructure for the Home Lab.

Verified components include:

- Twingate Connector for private remote access
- HAProxy for HTTP/HTTPS traffic routing
- ddclient for dynamic DNS updates
- coTURN as supporting communication infrastructure

These components are documented as host/network infrastructure rather than standalone Home Lab applications.

Exact addresses, domains, credentials, tokens, and private routing configuration are intentionally excluded.
