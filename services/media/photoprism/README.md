# PhotoPrism

PhotoPrism is a current LF1-hosted Home Lab service for photo management.

The verified live inventory confirms the PhotoPrism application and its MariaDB dependency are running as Docker containers on LF1. PhotoPrism data is stored on dedicated LF1 storage.

Historical documentation from the earlier Raspberry Pi deployment is retained under `legacy/raspberry_pi_photoprism/` and should not be interpreted as the current deployment.

Sensitive configuration, credentials, private addressing, and exact operational paths are intentionally excluded.
